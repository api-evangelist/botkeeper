# Botkeeper

> Botkeeper is an AI-powered accounting-automation platform built for accounting
> firms. Its Botkeeper Infinite product automates transaction categorization,
> bank reconciliation, document handling and practice workflow for CPA firms and
> their small-business clients, backed by optional human accounting services.

Generated by the API Evangelist enrichment pipeline on 2026-08-08. Botkeeper does
not publish an llms.txt of its own (https://www.botkeeper.com/llms.txt returns
404), so this file is assembled from the company's public surface and from the
artifacts in this repository. Every URL below was probed.

## API surface

Botkeeper operates APIs but publishes no developer portal, no API reference and
no machine-readable specification. Its own status page is the only public place
the APIs are named.

- [Status page — the only public listing of Botkeeper's APIs](https://status.botkeeper.com/): names three first-party components under "Application Programming Interface (APIs)" — User API, Bookkeeping API, Tasks API.
- [Statuspage components API](https://status.botkeeper.com/api/v2/components.json): machine-readable component and status data.
- Partner Platform API host: https://ipa.botkeeper.com — AWS API Gateway; every path returns 403 {"message":"Missing Authentication Token"} without credentials.
- GraphQL: https://api.firm.ai/graphql — Apollo server; introspection returns UNAUTHENTICATED. No SDL is public.
- Dead host: https://api.botkeeper.com is a dangling CNAME to a retired Elastic Beanstalk environment and does not resolve.

## Authentication

- [OpenID Connect discovery (Amazon Cognito, Botkeeper production pool)](https://cognito-idp.us-east-1.amazonaws.com/us-east-1_MZqyuuurX/.well-known/openid-configuration): the only machine-readable contract Botkeeper has. Authorization endpoint https://login.auth.firm.ai/oauth2/authorize. Scopes: openid, email, phone, profile.
- [Two-factor authentication and SSO](https://www.botkeeper.com/en/knowledge/two-factor-authentication-and-single-sign-on-sso)

## Integrations

- [Botkeeper on Zapier](https://zapier.com/apps/botkeeper/integrations): 2 triggers, 3 write actions, 3 searches — the only publicly callable projection of the API.
- QuickBooks Online, QuickBooks Desktop export, and Xero are the supported general ledgers.
- Bank data via Smart Connect, using Finicity and Mastercard Data Connect-certified institutions.
